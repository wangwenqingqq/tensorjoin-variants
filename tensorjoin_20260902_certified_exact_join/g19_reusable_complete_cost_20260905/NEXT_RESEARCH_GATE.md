# Next research gate: a defensible contribution, not more packaging

This is a bounded next-action design, not an implemented mechanism or novelty
pass. Preserve G10's prior-art overlap findings, G13's local-only negative, G16's
60K early screen and G19's separate 4096 contract without pooling ratios.

## Decision order

1. Finish G19's predeclared complete-cost result, including a loss if observed.
   A positive result admits a fair comparator asset, not a database-paper thesis.
2. Lock one sentence stating a concrete work term eliminated beyond conventional
   quantization bounds, adaptive precision and a standard tree. If no such term
   can be stated and distinguished from the nearest primary literature, stop
   paper expansion rather than rename the existing cascade as a new planner.
3. Run a cheap Gate 0 comparison of problem, mechanism and contribution against
   the closest primary sources, starting from G10's actual source routes. Search
   current sources before a new novelty decision; old notes are not live truth.
4. Only a differentiated mechanism gets a frozen falsification test. Freeze the
   input/output predicate, workload selection, measured denominator, unchanged
   admitted G19 controls, added state/build/output costs and stop rule first.
   If two interacting changes are essential, use a predeclared 2x2 attribution
   test instead of presenting internal ablations as external superiority.

## What the current assets can and cannot support

- The cascade's selective numerical work is real on tested inputs. Dense TC
  work still scans the scheduled tile pairs; a small FP64 queue does not make
  the whole join output-sensitive.
- The new RT lifecycle/ID adapter, pinned-memory fix, Torch allocator cleanup
  and owned cuBLAS binding are comparator engineering, not TensorJoin novelty.
- Agreement with the frozen FP64 oracle is not a general exact-real predicate
  theorem. Full candidate coverage on a finite matrix is not a general RT
  traversal certificate. Neither claim may silently enter the manuscript.
- A scale crossover, if later measured, is a workload boundary; routing by N
  alone is not automatically a non-incremental mechanism. Do not search for
  favorable dataset/size cells solely to rescue a subsumed contribution.

## Minimum artifact before restarting paper prose

One-sentence thesis; contribution IDs; closest-prior-art differences; a
claim-evidence table with unknowns and counterevidence; a decisive same-contract
external comparison; and a measured mechanism attribution. Build the main
results table and mechanism figure from those artifacts before writing prose.
Until then preserve the manuscript and Overleaf project unchanged.
